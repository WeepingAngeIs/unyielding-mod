CREEPYEON — COBBLEMON ADD-ON
Minecraft Java 1.21.1. Built from the available Cobblemon 1.8.2 assets.

INSTALL
1. Copy this ZIP (without extracting) into your world's datapacks folder.
   Single player: .minecraft/saves/<world>/datapacks/
   Server: <world>/datapacks/ (the folder is often called world).
2. Copy the same ZIP into the client's resourcepacks folder and enable it.
   Everyone who should see the model needs the resource pack.
3. Restart the world/server and reload the client resource packs.
   This is a data/resource pack, not a JAR. Do not put it in mods/.

GET CREEPYEON (commands require cheats or operator permissions)
/pokegive @s creepyeon gender=female
/pokegive @s creepyeon gender=male
/pokespawn creepyeon gender=female
/pokespawn creepyeon gender=male

INCLUDED
Both variants. Female head/tail bows and blush; male fitted neck ribbon and
bow tie. No earrings. Eevee head/ruff, Espeon-derived body, skeletal details,
blood-colored paws, crimson eyes, animated idle, walk/swim, distinct portrait
poses, blink, and a deeper male cry. Named glow animation uses bright red
emissive eyes only. Bows and blood do not glow.
Stats: HP150 / Atk50 / Def120 / SpA50 / SpD120 / Spe100 (590 total).
Ghost/Normal follows the proposed lore. Synchronize / hidden Magic Bounce
and the Espeon learnset are inherited defaults, pending a custom learnset.
No wild spawn rules or Eevee evolution were added; obtain it with commands.
Shiny uses the same artwork. No separate shiny palette has been designed.

VALIDATION AND LIMITS
JSON, model references, texture atlases, bones, animation channels and ZIP
layout have been checked offline. Minecraft itself has not been run here;
this is the first installable build and needs an in-game visual check.
Browser-only polygon outlines were converted into small cuboids. The fitted
neck ribbon follows the same sampled surface using thin cuboid segments.
The idle loops blend at the seam. The named glow animation is available to
the poser; it does not automatically play continuously during idle.
National Pokedex number 2007 is a custom placeholder.
