BUZZEON 1.0.0 — UwU
Combined Cobblemon resource pack + datapack for Minecraft Java 1.21.1.
Target: Cobblemon 1.8.x. Requires Cobblemon; this ZIP is not a Java mod.

INSTALL — USE THE SAME ZIP IN BOTH LOCATIONS; DO NOT UNZIP
Singleplayer:
1. Copy the ZIP into your instance resourcepacks folder and enable it in Resource Packs.
2. Copy the same ZIP into saves/<world>/datapacks/.
3. Restart the game and open the world.
Dedicated server:
1. Copy the ZIP into the server world/datapacks/ folder and restart the server.
2. Every player must install and enable the same ZIP in their client resourcepacks folder.
Do not place this ZIP in mods. Resource pack alone supplies visuals, not the species.

GET BUZZEON — requires command permission
/pokegive @s buzzeon gender=male level=50
/pokegive @s buzzeon gender=female level=50
/pokespawn buzzeon gender=female level=50
Choose its moves in the Pokemon summary move-selection interface.
All 55 moves are level-1 learnset entries, not 55 simultaneous battle slots.

CONTENTS
Bug/Flying; 100 HP / 140 Attack / 80 Defense / 15 SpA / 80 SpD / 135 Speed (550).
Abilities: Swarm, Compound Eyes; hidden Tinted Lens.
Both sexes; female antenna hearts and eyelashes. Same stats/move pool for both.
Grounded idle with straight supporting legs, a paw wave, head/ear/tail movement.
Moving legs during hover and flight. Thick, recessed, fluffy block ears.
Ground, walking, flying, hovering and sleeping poses wired to the exported animations.
Cry/recoil/faint and other named animation clips are included.
No custom cry audio, distinct shiny palette, natural spawn rules or Eevee evolution yet.
Obtain by command. Shiny uses the same artwork. No vanilla species is overwritten.
Custom dex number 9310; check for conflicts if combining with other custom species packs.

VALIDATION
JSON, resource references, skeleton references and all 55 move IDs were checked locally
for syntax and internal consistency. Not loaded or tested inside Minecraft; installed
Cobblemon move availability and runtime rendering still need an in-game test.
