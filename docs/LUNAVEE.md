# Lunavee — UwU

Separate Fairy/Dark Fakemon based on the supplied moon-and-stars reference. Original cuboid model, texture atlas, idle/walk/sleep animations. Provisional stats: 95/45/85/110/110/80 (525 total). Synchronize; hidden Magic Bounce. No evolution or natural spawning configured.

Install Lunavee.zip alongside Mawonna.zip in the server world datapacks and every client resourcepacks folder; enable the client pack and restart the server. Use `/pokespawn lunavee` or `/pokegive @s lunavee`.

Initial prototype: visual resemblance and animations require in-game review. No unique cry or shiny palette yet. Runtime compatibility has not been verified. Geometry imports into Blockbench as Bedrock geometry.
