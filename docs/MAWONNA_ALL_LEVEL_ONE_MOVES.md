# Mawonna: every named ordinary move from level 1

**Species:** `mawile_custom:mawile_third_evolution` (female-only)

**Result:** All **841** regular, English-named moves in the cross-checked move catalog are available via `1:<move_id>`. This update added **738** previously unavailable level-1 unlocks, and removed two previously added untranslated level-1 Torque entries (`magicaltorque`, `noxioustorque`) so they do not show raw identifiers. The previous learnset already included 103 of these moves at level 1.

**How it works:** Cobblemon still permits **four active move slots**. Level-1 moves are available without earning more experience, but players select the desired moves through the Pokémon move-relearn interface. Adding a move here does not automatically assign all moves to the Pokémon's four active slots. Some moves may not have their full mechanics implemented in your specific pack; the game was not run for this update.

**Preserved:** Original cry routing and Mawonna's 1.5-second custom cry, model, textures, animations, statistics, abilities, evolutions, gender ratio, other TM/tutor/egg/legacy entries. Unrelated Pokémon and other files were not edited.

**Excluded** from the named, normal learnset: Z-Moves, Dynamax and G-Max attacks, custom/CAP or zero-number move placeholders, dynamic Hidden Power types, Struggle and six identifiers without a normal Cobblemon English name in the cross-checked language data: `blazingtorque`, `combattorque`, `magicaltorque`, `nihillight`, `noxioustorque`, `wickedtorque`.

**Catalog sources:** [Pokémon Showdown standard move records](https://github.com/smogon/pokemon-showdown/blob/master/data/moves.ts) and [Cobblemon English move names](https://github.com/Cobblemon-Global/Cobblemon/blob/main/common/src/main/resources/assets/cobblemon/lang/en_us.json). This is a name-and-format cross-check, not a guarantee that every move works on Cobblemon 1.8.2.

## Installation

1. Download the updated [`Mawonna`](../Mawonna) file from GitHub's main branch using **Download raw file**.
2. Name it `Mawonna.zip` locally (the stored GitHub file is an extensionless ZIP).
3. Replace your old Mawonna addon in the server/world datapacks folder and enabled client resourcepacks (or whichever copy you normally use for the model/audio).
4. Reload data or restart the server and client, and disable/delete obsolete duplicate copies.
5. Obtain Mawonna and open the Pokémon's move-relearn interface. Search for moves such as Absorb, Acrobatics, Draco Meteor, Fire Fang and Moonblast. The 841 named entries should be listed from level 1, although usability of every move remains untested in-game.
